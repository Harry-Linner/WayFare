WayFare MVP Portable Quick Start
================================

1. Double-click "WayFare.exe"
   - or double-click "Start WayFare.bat"

2. Wait for your browser to open automatically.
   - If it does not open, visit:
     http://127.0.0.1:37880

3. Inside the app, test the two core areas:

   Knowledge Base
   --------------
   - Create a knowledge base
   - Upload one or more PDF/files
   - Click "打开" to preview in a new tab
   - Restart the app and confirm the knowledge base still exists

   Schedule Board
   --------------
   - Click "开启提醒"
   - Click "5 分钟后提醒我"
   - Wait for the browser notification
   - Test 完成 / 延后 10 分钟 / 改期 / 删除

Notes
-----
- Data is stored locally in the "data" folder.
- Uploaded files are stored in the "uploads" folder.
- Logs are written to the "logs" folder.
- If 37880 is occupied, the app will try the next available port.
- Browser notification permission must be allowed for reminder testing.
