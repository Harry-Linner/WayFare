# 谪仙人：李白生平简志

李白（701年－762年），字太白，号青莲居士，是唐代伟大的浪漫主义诗人，被后人誉为**“诗仙”**。

## 1. 少年逸事（701-724）

李白出生于中亚碎叶城（今吉尔吉斯斯坦境内），约五岁时随父迁居四川绵州昌隆县。

- **才华横溢**：少年时代的李白遍读群书，喜好剑术，轻财好施。
- **隐居山林**：曾在戴天山大明寺读书，这段经历为其诗歌中的自然灵性埋下了伏笔。

## 2. 辞亲远游（724-742）

二十四岁时，李白“辞亲远游”，离开四川，开始了他漫游全国的生涯。

- **仗剑天涯**：他顺长江而下，经过三峡，到达荆州、洞庭湖等地。
- **结交名流**：在漫游中，他结识了孟浩然等著名诗人，并在安陆（今湖北）与前宰相许圉师的孙女结婚。

## 3. 供奉翰林（742-744）

这是李白政治生涯的巅峰。经由玉真公主和贺知章的荐举，唐玄宗征召李白入京。

- **力士脱靴**：在长安，他担任翰林供奉。虽然深受玄宗赏识，但他放浪不羁的性格与腐朽的权臣阶层格格不入。
- **赐金放还**：天宝三载，李白感到政治抱负无法实现，请求还山，玄宗赐金放还。

## 4. 晚年飘零与病逝（744-762）

离开长安后，李白在洛阳遇到了**杜甫**，两位伟大的诗人共同游历，成就了中国文学史上最著名的友谊。

- **安史之乱**：叛乱爆发后，李白加入永王李璘的幕府。后因永王争权失败，李白受牵连被流放夜郎。
- **遇赦即还**：流放途中遇到大赦，他惊喜交加，写下了名篇《早发白帝城》。
- **生命终点**：762年，李白病逝于安徽当涂，享年六十二岁。
